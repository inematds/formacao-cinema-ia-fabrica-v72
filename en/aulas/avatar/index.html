Lesson 7 · 14 min

Talking avatar: studio, voice and consent

A talking avatar is the most expensive step in the factory and the most sensitive: it's a person's face and voice. In this lesson you'll see how the studio fits into the pipeline and write two pieces of your own: the avatar's consent form and a gate that doesn't let any generation start without a valid consent form.

Start the lesson

In this lesson you will

  1. 1Whose avatar it can be: only the person's own, with a consent form
  2. 2The seven fields of the consent form: person, what it authorizes, use, languages, validity, revocation and label
  3. 3A gate in a script before the studio, because the engine's own is just a written rule
  4. 4HeyGen's Avatar V as a dated example (Apr/2026), not as a fixed step

Goal: write the consent form for your avatar and put in a gate that closes any generation without a valid consent form.

01 · The path to the studio

Click each step. The studio only opens after the gate.

Click each block in the diagram to see what it does.

explicavideos and refazvideo ask for the APROVADO_HEYGEN file before start, but the code doesn't check it. The gate in this lesson is the one that really closes.

02 · The studio, in Oct/2026

Dated example: names and features change. What doesn't change is the consent form.

1. HeyGen

Avatar V, introduced in Apr/2026: identity created from about 15 s of footage, separating identity from appearance; in May/2026, motion direction in natural language (research §3). It's the studio INEMA's engines use, through the subscription.

2. Others

Synthesia Express-2 (Sep/2025, full body). Hedra Omnia and OmniHuman 1.5 appear in secondary sources: reported, not confirmed in an official source as of 10/19/2026.

3. Lip sync

In generators with native audio, the mouth comes out together with the speech. In avatars, the studio syncs from the audio or from the text. Generators and native audio: course 1.

4. Label and law

It also works with no avatar at all: local voice and scenes, like the demo in lesson 3 and course 3. The AI-generated content label, image and voice rights, and the AI Act are covered in course 2, lesson 7. Here the consent form only requires that the label exists and mentions AI.

04 · The gate

The script doesn't call any studio: it only decides whether you can open the studio and how many seconds you will ask for.

File · kit/portao-avatar.sh
#!/usr/bin/env bash
# portao-avatar.sh — porta de entrada de qualquer geração de avatar: sem termo conferido, nada segue.
# Uso: bash portao-avatar.sh <termo.md> <roteiro.txt>
# Não chama estúdio nenhum: só decide se você PODE abrir o estúdio, e quantos minutos vai pedir.
K=$(cd "$(dirname "$0")" && pwd)
termo="${1:?uso: portao-avatar.sh <termo.md> <roteiro.txt>}"; roteiro="${2:?falta o roteiro}"
python3 "$K/conferir-consentimento.py" "$termo" || { echo "PORTÃO FECHADO: corrija o termo antes de gerar"; exit 1; }
p=$(wc -w < "$roteiro")
echo "roteiro: $p palavras ≈ $(( (p * 60 + 139) / 140 )) s a 140 palavras/min"
echo "PORTÃO ABERTO: pode levar ao estúdio (a geração gasta crédito: confira o plano antes)"
Terminal · gate open and closed
K=~/projetos/formacao-cinema-ia-fabrica-v72/kit; X=$K/exemplos/a7-termo
bash "$K/portao-avatar.sh" "$X/termo.md" "$X/roteiro.txt"; echo "saída: $?"
bash "$K/portao-avatar.sh" "$X/termo-sem-rotulo.md" "$X/roteiro.txt"; echo "saída: $?"
Example from the repository
OK: termo de Ana Exemplo · 7 campos · válido até 31/12/2027
roteiro: 37 palavras ≈ 16 s a 140 palavras/min
PORTÃO ABERTO: pode levar ao estúdio (a geração gasta crédito: confira o plano antes)
saída: 0
FALTA: Rótulo

saída: 1

Put the gate call as the first line of your production script, before start: with set -e, exit code 1 stops everything.
