Lesson 2 · 18 min

Explainer with avatar and voice: explicavideos under the hood

explicavideos turns a script into an explainer video with avatar, voice, animated scenes and captions. Only one part is expensive: the avatar studio. In this lesson you run the engine's tests and build scenes, blocks and templates from a script of your own, stopping before the studio.

Start the lesson

In this lesson you will

  1. 1The engine's stages, from script to finished video
  2. 2The scene format: title, chapter, speech, labels and takeaway
  3. 3Why scenes become blocks and what the per-block limit does
  4. 4Where the studio gate is and what --help says the code does not do

Goal: run the explicavideos tests and build scenes and blocks from a script of your own without generating anything in the avatar studio.

02 · The engine at a pinned commit

Clones it, shows the version, reads --help and runs the tests. The tests simulate the network and swap the render for a command that fails if called: nothing leaves your machine.

Terminal · explicavideos tests
E=${TMPDIR:-/tmp}/ensaio-fabrica/a2; rm -rf "$E"; mkdir -p "$E"; cd "$E"
git clone -q https://github.com/inematds/explicavideos.git && cd explicavideos
git checkout -q 604fc74 && cat VERSION
python3 explica.py --help | grep -E "^  (prepare|preview)"
python3 -m unittest discover -s tests > testes.log 2>&1; echo "saída: $?"
grep -E "^(Ran|OK)" testes.log | sed 's/ in .*s$//'
Example from the repository
2.13.10
  prepare   monta cenas, blocos (<= 4.400 caracteres) e templates. Não gera nada no HeyGen.
  preview   renderiza o bloco 1 localmente, sem avatar, para conferir o layout.
saída: 0
Ran 50 tests
OK

The block drops the time from the Ran 50 tests line (it changes on every run). Note the text of preview: it says it renders, but see the next tab.

At commit 604fc74, preview calls build_final_block.py pt 1 --preview, which only writes the HTML of block 1 to layout-preview/, with placeholder timings and the notice "PRÉVIA VISUAL · SEM NARRAÇÃO" in place of the avatar. No MP4 comes out. When the help text and the code disagree, the code wins.

04 · When a scene doesn't fit

The engine refuses to cut a speech. With the limit at 140, the first scene (155 characters) already overflows.

Terminal · limit exceeded
E=${TMPDIR:-/tmp}/ensaio-fabrica/a2; cd "$E/explicavideos"
sed 's/"max_chars": 300/"max_chars": 140/' "$E/ensaio.json" > "$E/curto.json"
sed -i 's#"output": "[^"]*"#"output": "'"$E"'/saida-curta"#' "$E/curto.json"
python3 explica.py --config "$E/curto.json" prepare 2>&1 | grep -E "^ValueError"; echo "saída: ${PIPESTATUS[0]}"
Example from the repository
ValueError: Scene 1 exceeds limit; split its narration before submitting
saída: 1

The fix is to split the scene's speech in two, not to raise the limit: the real limit comes from the studio.

06 · What comes before the studio

Three things to check before any start.

1. Approval

The engine's --help requires an APROVADO_HEYGEN file in the output, with the avatar owner's authorization and the number of blocks and minutes. It is a written rule, not a block in the code: your gate (lesson 7) is what really closes it.

2. Your own avatar

The engine was built for Nei's avatar and voice, with his consent. In your use, the avatar is yours, with a signed consent form. Someone else's avatar without a consent form, no.

3. Profiles

Profiles belong to v2: without profile_visual, you get the aula profile; with "profile_visual": "viral", the viral profile (faster cuts), checked by engine/v2/qa_viral.py, which prints APROVADO, APROVADO COM AVISO or REPROVADO.

4. The v2 on top

The v2 does not generate the avatar again: it starts from a finished v1 production and redoes the visuals of each block with a visual script driven by spoken cues, the same concept the refazvideo validator checks in lesson 4.

README commands (only described here, because they need the avatar's transcribed speech): engine/v2/setup_output.py → engine/v2/build_block.py 1 --strict → engine/v2/run_lane.sh 1 2 3.

08 · Practice

From the tested engine to the scenes of your next video.

Run the "explicavideos tests" block.

Done when: The output shows 2.13.10, saída: 0, Ran 50 tests and OK.

E2 · Scenes and blocks

5 min

Run the "prepare and status" block with the kit's four scenes.

Done when: {"blocks": 2, "scenes": 4, "topics": 0, "chars": 561}, saída: 0 and the status with "prepared": 2.

E3 · Your script

15 min

Ask your agent for the scenes of an explainer of your own (5 to 8 scenes, each spoken line up to 600 characters) in the same format as cenas-pt.json. Save it to ${TMPDIR:-/tmp}/ensaio-fabrica/a2/minhas-cenas.json, change the scene_files in the config, and run prepare with max_chars 4400.

Done when: cd ${TMPDIR:-/tmp}/ensaio-fabrica/a2/explicavideos && python3 explica.py --config ../ensaio.json prepare; echo "saída: $?" → one line {"blocks": …, "scenes": N, …} with the N of your scenes and saída: 0.
