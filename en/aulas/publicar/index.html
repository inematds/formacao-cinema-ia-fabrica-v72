Lesson 8 · 18 min

Publishing a video: caption, thumb, three languages and YouTube

The factory's last engine takes the finished video to YouTube with title, description, tags, cover and captions. yt-pubx has a dry-run mode that builds everything and stops before sending. In this lesson you do a dry run with no model and no account, see the most common error and close the course with the plan for your first video.

Start the lesson

In this lesson you will

  1. 1Isolate the dry-run configuration with YTPUBX_CONFIG and YTPUBX_DATA
  2. 2When yt-pubx calls a model and how to do a dry run with none
  3. 3The cover built on your machine from an image and a phrase
  4. 4The dated plan for your first video, lesson by lesson

Goal: do a dry run of publishing with yt-pubx in --dry-run mode, with no model and no upload, and build the plan for your first video.

yt-pubx 2.4.0 (commit f9842a1, MIT license), read on 10/19/2026. Schedule, queue and channel on autopilot: the From chat to agent program.

02 · Dry run with no model and no account

The two variables send the config and the jobs to the dry-run folder: your real configuration is not touched. Title, description and tags by hand and --sem-thumb: no model is called.

Terminal · publishing dry run
E=${TMPDIR:-/tmp}/ensaio-fabrica/a8; rm -rf "$E"; mkdir -p "$E"; cd "$E"
git clone -q https://github.com/inematds/yt-pubx.git && git -C yt-pubx checkout -q f9842a1
export YTPUBX_CONFIG="$E/config" YTPUBX_DATA="$E/dados"
ffmpeg -v error -f lavfi -i color=c=0x0c0c10:s=1280x720:d=5 -f lavfi -i anullsrc=r=48000:cl=stereo -t 5 -shortest -c:v libx264 -pix_fmt yuv420p -c:a aac ensaio.mp4
./yt-pubx/yt-pubx init > /dev/null; echo "init: $?"
./yt-pubx/yt-pubx publicar ensaio.mp4 --dry-run --sem-thumb \
  --title "Ensaio da fábrica" --description "Vídeo de ensaio, 5 s, sem envio." --tags "ensaio,fabrica" 2>&1 \
  | grep -E "^(TÍTULO|TAGS|THUMB)|nada foi enviado" | sed "s/^\[yt-pubx [0-9:]*\] //"; echo "saída: ${PIPESTATUS[0]}"
Example from the repository
init: 0
TÍTULO: Ensaio da fábrica
TAGS: ensaio, fabrica
THUMB: None
--dry-run: nada foi enviado.
saída: 0

The init creates an example channel ("principal") in the dry-run folder. The block cuts the time from the start of the log lines. The plano.json stays in dados/trabalhos/.

In the code of commit f9842a1: if the title or description is missing, or if the cover is missing (no --thumb, no --sem-thumb and no phrase and scene), yt-pubx asks the Codex on your subscription. In the course dry run, everything is done by hand so nothing leaves your machine.

03 · The most common error

With no title, no description and no context, yt-pubx has nothing to write from and stops before calling any model.

Terminal · dry run without text
cd ${TMPDIR:-/tmp}/ensaio-fabrica/a8
export YTPUBX_CONFIG="$PWD/config" YTPUBX_DATA="$PWD/dados"
./yt-pubx/yt-pubx publicar ensaio.mp4 --dry-run --sem-thumb 2>&1 | grep "ERRO" | sed "s/^\[yt-pubx [0-9:]*\] //"; echo "saída: ${PIPESTATUS[0]}"
Example from the repository
ERRO: sem --title/--description e sem --contexto/--contexto-arquivo/--legenda: não há do que escrever
saída: 1

The message already names the three ways out: pass the text by hand, give a context, or give the video's caption file (the last two call Codex).

04 · The cover composed on your machine

One art image, one short phrase and one scene: yt-pubx composes the 1280×720 cover with Pillow, no model needed.

Terminal · local cover
cd ${TMPDIR:-/tmp}/ensaio-fabrica/a8
export YTPUBX_CONFIG="$PWD/config" YTPUBX_DATA="$PWD/dados"
ffmpeg -v error -y -f lavfi -i "testsrc2=s=1280x720" -frames:v 1 arte.png
./yt-pubx/yt-pubx publicar ensaio.mp4 --dry-run --title "Ensaio da fábrica" --description "Vídeo de ensaio, 5 s, sem envio." \
  --tags "ensaio,fabrica" --frase-thumb "A FÁBRICA" --cena-thumb "mesa de edição" --thumb-arte arte.png 2>&1 \
  | grep -E "^THUMB|nada foi enviado" | sed -E "s/^\[yt-pubx [0-9:]*\] //; s#/[0-9]{8}-[0-9]{6}-#/<data>-#"; echo "saída: ${PIPESTATUS[0]}"
f=$(ls dados/trabalhos/*/thumb.jpg | tail -1); python3 -c "from PIL import Image; print('thumb:', Image.open('$f').size)"
Example from the repository
THUMB: /tmp/ensaio-fabrica/a8/dados/trabalhos/<data>-ensaio-mp4/thumb.jpg
--dry-run: nada foi enviado.
saída: 0
thumb: (1280, 720)

The date and time in the job folder name were replaced with <data>. In this capture the art is an ffmpeg test pattern; in yours, use a frame from your own video.

05 · Three languages

One video per language, each with its own title and its own caption.

1. Video

explicavideos produces PT, EN and ES when the config lists all three languages and there is a reviewed scenes file for each language (lesson 2). Translating the script and captions: the translator from your subscription, never an unreviewed step.

2. Captions

One SRT per language. In yt-pubx, --legenda uploads the SRT along with the video; with --sem-legenda it only serves as context.

3. Publishing

One call per language, with --idioma and the title in that language. If the channel is single-language, the other languages go to the right channel or to the project's player.
