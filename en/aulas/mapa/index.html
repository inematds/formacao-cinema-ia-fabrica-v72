Lesson 1 · 12 min

The factory map: from what you have to the right engine

INEMA has one video engine for each case: explainer, demo, documentary, short, publishing. Picking the wrong engine costs hours. In this lesson you turn the table in the Videos area into a command that tells you which one to use, and you get your machine ready for the next seven lessons.

Start the lesson

In this lesson you will

  1. 1The 14 rows of the "Where to start" table in the Videos area
  2. 2What every engine has in common: a declared input and a gate before the credit
  3. 3Check git, Python, Node, and FFmpeg before cloning the engines
  4. 4In which lesson (or sister course) each engine appears

Goal: pick the right engine for what you have and what you want, with the Videos area table turned into a command.

02 · Three rules that apply to every engine

They are what makes the factory repeatable.

1. Pinned commit

The engines change every week. The labs clone each one from GitHub and check out an exact commit, the same one the lesson's output was captured from.

When you want the new version, change the commit and run the block again: if the output changes, you know it was the engine.

2. Declared input

Each engine reads one file: scenes in JSON, actions.json, a theme in YAML, a script in Markdown. The agent writes that file; the engine does the rest.

Reviewing the file is cheap. Reviewing the finished video is expensive.

3. Gate before credits

Avatar, AI-generated video, and uploading to YouTube sit on the other side of a gate: human approval, a consent form, dry-run mode.

In this course nothing goes past the gate. You learn to get right up to it with everything checked.

Exampleexplicavideos builds scenes and blocks without touching the avatar studio; only the start command generates video, and --help itself warns about that in capital letters.

03 · Set up your machine

Clone the course repository into ~/projetos and check the four tools that every lesson uses.

Once · clone the course
mkdir -p ~/projetos && cd ~/projetos
git clone https://github.com/inematds/formacao-cinema-ia-fabrica-v72.git
Terminal · check the environment
for c in git python3 node ffmpeg; do printf "%-8s" "$c"; command -v $c > /dev/null && echo ok || echo FALTA; done
node --version; ffmpeg -version | head -1 | cut -d' ' -f1-3; python3 --version
Example from the repository
git     ok
python3 ok
node    ok
ffmpeg  ok
v24.13.0
ffmpeg version 6.1.1-3ubuntu5
Python 3.12.3

The versions are the ones on this machine. Any Node 22+ and FFmpeg 6+ will do; the line that matters is ok on all four tools.

Install it with your system's package manager (apt, brew) and run the block again. On Windows, run everything inside WSL: the engines call bash, ffmpeg, and Unix paths.

04 · The table turned into a command

The kit has all 14 rows in qual-motor.py. You pass what you have and what you want; it answers with the engine and the lesson.

Terminal · ask the map
K=~/projetos/formacao-cinema-ia-fabrica-v72/kit
python3 "$K/qual-motor.py" --lista | tail -3
python3 "$K/qual-motor.py" tema short; echo "saída: $?"
python3 "$K/qual-motor.py" tema podcast; echo "saída: $?"
Example from the repository
frase         clipe        → musicavideo (fora deste curso (guia da área Vídeos))
video-pronto  publicar     → yt-pubx (aula 8)
14 linhas
Short ou reel 9:16 com gancho
Use: MakeShorts ou cardshorts · aprender: aula 5
saída: 0
SEM MOTOR: com 'tema' a tabela tem: explicativo, documentario, short
saída: 1

A combination that isn't in the table prints SEM MOTOR and exits with code 1, listing what exists for that input. Use --lista to see the 14 rows.
