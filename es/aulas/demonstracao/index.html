Clase 3 · 20 min

Demostración de app, clic a clic

Para mostrar una app, la pantalla real convence más que cualquier animación. El video-demonstrativo dirige un navegador por tu app, toma una foto por paso con la posición del elemento clicado, narra con voz local y arma el video con cursor y zoom. En esta clase haces todo eso, con una app de ejemplo, sin crédito.

Comenzar la clase

En esta clase vas a

  1. 1El actions.json: URL, tamaño de pantalla y un paso por clic
  2. 2La captura con agent-browser: foto y posición del objetivo de cada paso
  3. 3Narración local por paso, con voz Kokoro, sin servicio externo
  4. 4La composición generada y el render con la versión de HyperFrames fija

Objetivo: capturar una app paso a paso con el agente y renderizar la demostración narrada que pasa el verificador.

03 · Capturar la app

El bloque levanta la app en un puerto local, ejecuta la captura en una sesión propia de agent-browser y cierra todo al final.

Terminal · capturar la app
K=~/projetos/formacao-cinema-ia-fabrica-v72/kit
command -v agent-browser > /dev/null || { echo "FALTA agent-browser: npm i -g agent-browser@0.6.0 && agent-browser install"; exit 1; }
E=${TMPDIR:-/tmp}/ensaio-fabrica/a3; rm -rf "$E"; mkdir -p "$E"; cd "$E"
git clone -q https://github.com/inematds/video-demonstrativo.git && git -C video-demonstrativo checkout -q a87b382
cp video-demonstrativo/skills/video-demonstrativo/scripts/capture.mjs "$K/exemplos/a3-demo/actions.json" .
python3 -m http.server 18791 --bind 127.0.0.1 --directory "$K/exemplos/a3-demo" > servidor.log 2>&1 & S=$!
until curl -s -o /dev/null http://127.0.0.1:18791/; do sleep 0.3; done
export AGENT_BROWSER_SESSION=ensaio-fabrica
node capture.mjs actions.json > captura.log 2>&1; echo "captura: $?"
agent-browser close > /dev/null 2>&1; kill $S
ls assets/shots
python3 -c "import json; s=json.load(open('steps.json')); print('passos no steps.json:', len(s['steps']))"

Una foto por paso y el steps.json con las cajas medidas. El until curl espera a que el puerto responda antes de abrir el navegador; un sleep fijo falla en una máquina cargada.

El bloque se detiene en la primera línea con FALTA agent-browser: npm i -g agent-browser@0.6.0 && agent-browser install. El paquete es Apache-2.0 (npm, 19/10/2026); el install descarga el navegador. La sesión AGENT_BROWSER_SESSION=ensaio-fabrica evita tocar otra sesión que tengas abierta.

04 · Narrar y montar

Crea el proyecto HyperFrames, copia fotos, fuentes y steps.json, genera una frase por paso y escribe la composición.

Terminal · narrar y montar
export HYPERFRAMES_NO_TELEMETRY=1 NO_COLOR=1
E=${TMPDIR:-/tmp}/ensaio-fabrica/a3; S=$E/video-demonstrativo/skills/video-demonstrativo
cd "$E" && rm -rf demo
npx -y hyperframes@0.8.176 init demo --non-interactive > init.log 2>&1; echo "init: $?"
cd demo && mkdir -p assets/audio assets/txt
cp -r ../assets/shots assets/ && cp -r "$S/assets/fonts" assets/ && cp ../steps.json .
cp "$S/scripts/composition-template.mjs" build-demo.mjs
node -e 'const d=require("./steps.json"); const l=d.steps.map(s=>s.narration); l.push(d.ctaNarration);
l.forEach((t,i)=>require("fs").writeFileSync(`assets/txt/s${i+1}.txt`, t.trim()+"\n")); console.log("falas:", l.length)'
for f in assets/txt/s*.txt; do
  n=$(basename "$f" .txt)
  npx -y hyperframes@0.8.176 tts "$f" --voice pf_dora --lang pt-br --speed 0.98 --output "assets/audio/$n.wav" > /dev/null 2>&1 || echo "falhou $n"
done
ls assets/audio | wc -l
node build-demo.mjs | head -1

Seis frases de narración (cinco pasos y el cierre), seis WAVs. El TOTAL sale de la suma de las narraciones con un margen antes y después de cada una: si cambias la narración, cambia la duración.

La skill en el commit a87b382 llama a npx hyperframes sin versión, y el curso anterior fijaba 0.8.66. Los bloques de este curso usan hyperframes@0.8.176 (npm, 19/10/2026) y HYPERFRAMES_NO_TELEMETRY=1. El porqué, y el resto de HyperFrames, está en el curso 3.

05 · Render y verificación

Check, render en borrador y el verificador con la duración que la propia composición declara.

Terminal · render y verificar
export HYPERFRAMES_NO_TELEMETRY=1 NO_COLOR=1
K=~/projetos/formacao-cinema-ia-fabrica-v72/kit
cd ${TMPDIR:-/tmp}/ensaio-fabrica/a3/demo
npx -y hyperframes@0.8.176 check 2>&1 | grep -E "◇|✗" | head -3
npx -y hyperframes@0.8.176 render --quality draft --workers 2 --quiet --output renders/demo.mp4 > render.log 2>&1
echo "render: $?"
D=$(grep -o 'id="root"[^>]*data-duration="[0-9.]*"' index.html | grep -o "[0-9.]*\"$" | tr -d \")
echo "duração pedida: $D s"
python3 "$K/conferir.py" renders/demo.mp4 "$D" 1920x1080 --audio; echo "saída: $?"

En esta máquina el render de 30 s tardó menos de un minuto (medido fuera de la captura; render por software, --workers 2). La duración pedida sale del data-duration de la raíz, así que el verificador sirve para cualquier guion tuyo.
