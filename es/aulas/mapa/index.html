Clase 1 · 12 min

El mapa de la fábrica: de lo que tienes al motor correcto

INEMA tiene un motor de video para cada caso: explicativo, demostración, documental, short, publicación. Equivocarte de motor cuesta horas. En esta clase conviertes la tabla del área Vídeos en un comando que responde cuál usar, y preparas la máquina para las próximas siete clases.

Comenzar la clase

En esta clase vas a

  1. 1Las 14 líneas de la tabla "Por onde começar" del área Vídeos
  2. 2Lo que todo motor tiene en común: entrada declarada y compuerta antes del crédito
  3. 3Verificar git, Python, Node y FFmpeg antes de clonar los motores
  4. 4En qué clase (o curso hermano) aparece cada motor

Objetivo: elegir el motor correcto para lo que tienes y quieres, con la tabla del área Vídeos convertida en comando.

01 · De lo que tienes al motor

Haz clic en cada etapa.

Haz clic en cada bloque del diagrama para ver qué hace.

La tabla es la del área Vídeos de INEMA (eventos.inema.pro/videos/, sección "Por dónde empezar"), leída el 19/10/2026.

02 · Tres reglas que valen para todos los motores

Es lo que hace que la fábrica sea repetible.

1. Commit fijo

Los motores cambian cada semana. Las prácticas clonan cada uno desde GitHub y hacen checkout de un commit exacto, el mismo en el que se capturó la salida de la lección.

Cuando quieras la versión nueva, cambia el commit y ejecuta el bloque de nuevo: si la salida cambia, sabes que fue el motor.

2. Entrada declarada

Cada motor lee un archivo: escenas en JSON, actions.json, tema en YAML, guion en Markdown. El agente escribe ese archivo; el motor hace el resto.

Revisar el archivo es barato. Revisar el video terminado es caro.

3. Compuerta antes del crédito

El avatar, el video generado por IA y el envío a YouTube quedan del otro lado de una compuerta: aprobación humana, formulario de consentimiento, modo de ensayo.

En este curso nada pasa de la compuerta. Aprendes a llegar hasta ella con todo verificado.

EjemploExplicavideos monta escenas y bloques sin tocar el estudio de avatar; solo el comando start genera video, y el propio --help lo avisa en mayúsculas.

03 · Preparar la máquina

Clona el repositorio del curso en ~/projetos y verifica las cuatro herramientas que usan todas las lecciones.

Una vez · clonar el curso
mkdir -p ~/projetos && cd ~/projetos
git clone https://github.com/inematds/formacao-cinema-ia-fabrica-v72.git
Terminal · verificar el entorno
for c in git python3 node ffmpeg; do printf "%-8s" "$c"; command -v $c > /dev/null && echo ok || echo FALTA; done
node --version; ffmpeg -version | head -1 | cut -d' ' -f1-3; python3 --version
Ejemplo del repositorio
git     ok
python3 ok
node    ok
ffmpeg  ok
v24.13.0
ffmpeg version 6.1.1-3ubuntu5
Python 3.12.3

Las versiones son las de esta máquina. Cualquier Node 22+ y FFmpeg 6+ sirven; la línea que importa es ok en las cuatro herramientas.

Instálalo con el gestor de tu sistema (apt, brew) y ejecuta el bloque de nuevo. En Windows, ejecuta todo dentro de WSL: los motores llaman a bash, ffmpeg y rutas Unix.

04 · La tabla convertida en comando

El kit trae las 14 filas en qual-motor.py. Tú pasas lo que tienes y lo que quieres; él responde el motor y la lección.

Terminal · preguntarle al mapa
K=~/projetos/formacao-cinema-ia-fabrica-v72/kit
python3 "$K/qual-motor.py" --lista | tail -3
python3 "$K/qual-motor.py" tema short; echo "saída: $?"
python3 "$K/qual-motor.py" tema podcast; echo "saída: $?"
Ejemplo del repositorio
frase         clipe        → musicavideo (fora deste curso (guia da área Vídeos))
video-pronto  publicar     → yt-pubx (aula 8)
14 linhas
Short ou reel 9:16 com gancho
Use: MakeShorts ou cardshorts · aprender: aula 5
saída: 0
SEM MOTOR: com 'tema' a tabela tem: explicativo, documentario, short
saída: 1

Una combinación que no está en la tabla sale con SEM MOTOR y código 1, listando lo que existe para esa entrada. Usa --lista para ver las 14 filas.

05 · Los motores de este curso y los que quedan con los hermanos

El mapa cubre más de lo que enseña este curso. Sigue el enlace correcto.

1. Aquí

06 · Práctica

Máquina lista y tu primer caso en el mapa.

E1 · Entorno

5 min

Clona el curso y ejecuta el bloque "conferir o ambiente".

Listo cuando: Las cuatro líneas git, python3, node y ffmpeg terminan en ok, y node --version muestra v22 o más.

E2 · El mapa responde

5 min

Ejecuta el bloque "perguntar ao mapa".

Listo cuando: La salida tiene 14 linhas, Use: MakeShorts ou cardshorts · aprender: aula 5 con saída: 0 y SEM MOTOR: com 'tema' a tabela tem: explicativo, documentario, short con saída: 1.

E3 · Tu caso

5 min

Piensa en el próximo video que necesitas hacer. Encuentra su línea con --lista y pregúntale al mapa.

Listo cuando: python3 ~/projetos/formacao-cinema-ia-fabrica-v72/kit/qual-motor.py [tengo] [quiero]; echo "saída: $?" → una línea Use: … y saída: 0.
