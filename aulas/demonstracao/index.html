Aula 3 · 20 min

Demonstração de app, clique a clique

Para mostrar um app, a tela real convence mais que qualquer animação. O video-demonstrativo dirige um navegador pelo seu app, tira uma foto por passo com a posição do elemento clicado, narra com voz local e monta o vídeo com cursor e zoom. Nesta aula você faz isso inteiro, com um app de exemplo, sem crédito.

Começar a aula

Nesta aula você vai

  1. 1O actions.json: URL, tamanho da tela e um passo por clique
  2. 2A captura com o agent-browser: foto e posição do alvo de cada passo
  3. 3Narração local por passo, com voz Kokoro, sem serviço externo
  4. 4A composição gerada e o render com a versão do HyperFrames fixa

Objetivo: capturar um app passo a passo com o agente e renderizar a demonstração narrada que passa no conferidor.

03 · Capturar o app

O bloco sobe o app numa porta local, roda a captura numa sessão própria do agent-browser e fecha tudo no fim.

Terminal · capturar o app
K=~/projetos/formacao-cinema-ia-fabrica-v72/kit
command -v agent-browser > /dev/null || { echo "FALTA agent-browser: npm i -g agent-browser@0.6.0 && agent-browser install"; exit 1; }
E=${TMPDIR:-/tmp}/ensaio-fabrica/a3; rm -rf "$E"; mkdir -p "$E"; cd "$E"
git clone -q https://github.com/inematds/video-demonstrativo.git && git -C video-demonstrativo checkout -q a87b382
cp video-demonstrativo/skills/video-demonstrativo/scripts/capture.mjs "$K/exemplos/a3-demo/actions.json" .
python3 -m http.server 18791 --bind 127.0.0.1 --directory "$K/exemplos/a3-demo" > servidor.log 2>&1 & S=$!
until curl -s -o /dev/null http://127.0.0.1:18791/; do sleep 0.3; done
export AGENT_BROWSER_SESSION=ensaio-fabrica
node capture.mjs actions.json > captura.log 2>&1; echo "captura: $?"
agent-browser close > /dev/null 2>&1; kill $S
ls assets/shots
python3 -c "import json; s=json.load(open('steps.json')); print('passos no steps.json:', len(s['steps']))"

Uma foto por passo e o steps.json com as caixas medidas. O until curl espera a porta responder antes de abrir o navegador; sleep fixo falha em máquina carregada.

O bloco para na primeira linha com FALTA agent-browser: npm i -g agent-browser@0.6.0 && agent-browser install. O pacote é Apache-2.0 (npm, 19/10/2026); o install baixa o navegador. A sessão AGENT_BROWSER_SESSION=ensaio-fabrica evita mexer em outra sessão que você tenha aberta.

04 · Narrar e montar

Cria o projeto HyperFrames, copia fotos, fontes e steps.json, gera uma fala por passo e escreve a composição.

Terminal · narrar e montar
export HYPERFRAMES_NO_TELEMETRY=1 NO_COLOR=1
E=${TMPDIR:-/tmp}/ensaio-fabrica/a3; S=$E/video-demonstrativo/skills/video-demonstrativo
cd "$E" && rm -rf demo
npx -y hyperframes@0.8.176 init demo --non-interactive > init.log 2>&1; echo "init: $?"
cd demo && mkdir -p assets/audio assets/txt
cp -r ../assets/shots assets/ && cp -r "$S/assets/fonts" assets/ && cp ../steps.json .
cp "$S/scripts/composition-template.mjs" build-demo.mjs
node -e 'const d=require("./steps.json"); const l=d.steps.map(s=>s.narration); l.push(d.ctaNarration);
l.forEach((t,i)=>require("fs").writeFileSync(`assets/txt/s${i+1}.txt`, t.trim()+"\n")); console.log("falas:", l.length)'
for f in assets/txt/s*.txt; do
  n=$(basename "$f" .txt)
  npx -y hyperframes@0.8.176 tts "$f" --voice pf_dora --lang pt-br --speed 0.98 --output "assets/audio/$n.wav" > /dev/null 2>&1 || echo "falhou $n"
done
ls assets/audio | wc -l
node build-demo.mjs | head -1

Seis falas (cinco passos e o fecho), seis WAVs. O TOTAL vem da soma das falas com uma folga antes e depois de cada uma: mude a fala, muda a duração.

A skill no commit a87b382 chama npx hyperframes sem versão, e o curso antigo fixava 0.8.66. Os blocos deste curso usam hyperframes@0.8.176 (npm, 19/10/2026) e HYPERFRAMES_NO_TELEMETRY=1. O porquê, e o resto do HyperFrames, está no curso 3.

05 · Render e conferência

Check, render em rascunho e o conferidor com a duração que a própria composição declara.

Terminal · render e conferir
export HYPERFRAMES_NO_TELEMETRY=1 NO_COLOR=1
K=~/projetos/formacao-cinema-ia-fabrica-v72/kit
cd ${TMPDIR:-/tmp}/ensaio-fabrica/a3/demo
npx -y hyperframes@0.8.176 check 2>&1 | grep -E "◇|✗" | head -3
npx -y hyperframes@0.8.176 render --quality draft --workers 2 --quiet --output renders/demo.mp4 > render.log 2>&1
echo "render: $?"
D=$(grep -o 'id="root"[^>]*data-duration="[0-9.]*"' index.html | grep -o "[0-9.]*\"$" | tr -d \")
echo "duração pedida: $D s"
python3 "$K/conferir.py" renders/demo.mp4 "$D" 1920x1080 --audio; echo "saída: $?"

Nesta máquina o render de 30 s levou menos de um minuto (medido fora da captura; render por software, --workers 2). A duração pedida sai do data-duration da raiz, então o conferidor vale para qualquer roteiro seu.
